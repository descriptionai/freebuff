모든 절차는 명령프롬프트에서 한다.
1. node.js 홈페이지에서 .msi 다운 받아 설치 
2. node.js와 npm 설치
3. freebuff를 설치
4. 소스를 넣을 경로를 만들고 해당 경로로 이동
5. freebuff 라고 입력 하여 시작
6. 한국ip는 일부 제한이라 deepseek 밖에 안된다.
7. github 홈페이지 가입
8. 자동 배포를 위해 git, github cli 버전으로 다운 받고 설치
9. 소스 업로드 까지 진행한다
10. 차후에는 에이전트가 이 기록을 토대로 자동으로 배포한다.

[방명록 DB 페이지 추가 절차 - Supabase + Vercel]
11. db를 이용한 방명록 페이지를 만든다. DB=Supabase, 호스팅=Vercel (상세: README.md)
12. supabase.com 가입 → New project (Region: Southeast Asia Singapore) → SQL Editor에서 supabase/schema.sql 실행
13. (선택) Authentication → Providers → Email → Confirm email 끄기 (바로 로그인 테스트용)
14. Project Settings → API 에서 Project URL, anon key 복사 → js/config.js에 입력
15. index.html을 브라우저에서 열어 회원가입/로그인/글 작성/삭제 테스트
16. git으로 GitHub에 push (main 브랜치)
17. vercel.com 가입(GitHub 계정) → Add New Project → 저장소 Import → Framework: Other, Output Directory: . → Deploy
18. 이후 git push만 하면 Vercel이 자동으로 재배포됨
19. 차후 에이전트는 이 기록과 README.md를 보고 자동으로 배포한다.
